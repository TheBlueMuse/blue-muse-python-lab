# Caderno de aprendizagem

Aqui ficam as práticas curtas de Python, em ordem.

Cada aula terá:

- uma explicação simples;
- um exemplo criativo;
- um exercício;
- uma solução separada;
- uma pequena anotação sobre o que aprendi.

Começo: **zero absoluto**. Sem vergonha, sem pressa e sem pular degraus.
