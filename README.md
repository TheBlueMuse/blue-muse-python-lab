# Blue Muse Python Lab 🐍✨

Meu laboratório de aprendizagem de **Python do zero**, com foco em criatividade e aplicações práticas de inteligência artificial.

## Objetivo

Aprender Python passo a passo para criar ferramentas úteis para:

- AI art e organização de prompts;
- criação e planejamento de conteúdo;
- pequenas automações para fluxos criativos;
- futuros miniapps para o portfólio da The Blue Muse.

## Ponto de partida

Comecei sabendo apenas que Python é uma linguagem usada para programar computadores. Este repositório documenta o caminho real: exercícios pequenos, erros, descobertas e projetos que crescem comigo.

## Estrutura

- `caderno/` — aulas e exercícios para iniciantes;
- `projetos/` — miniapps e projetos de portfólio;
- `progresso.md` — registro do que já aprendi e dos próximos passos.

## Método

Uma sessão curta por dia útil:

1. um conceito explicado de forma simples;
2. um exemplo ligado ao trabalho criativo;
3. um pequeno exercício;
4. uma solução para conferir depois;
5. uma melhoria gradual deste repositório.
